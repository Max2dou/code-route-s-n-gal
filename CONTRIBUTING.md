# Contribution au Projet

Merci de votre intérêt! Voici comment contribuer.

## Comment Contribuer

1. **Fork** le repository
2. **Créez une branche**: `git checkout -b feature/nom`
3. **Faites vos changements**
4. **Committez**: `git commit -am 'Ajout de: description'`
5. **Poussez**: `git push origin feature/nom`
6. **Ouvrez une Pull Request**

## Types de Contributions

- Nouvelles questions de quiz
- Améliorations UX/UI
- Corrections de bugs
- Améliorations de la documentation

## Règles

- Questions basées sur le code sénégalais
- Inclure explications pour chaque réponse
- Vérifier l'exactitude
- Code propre et commenté

Merci!
