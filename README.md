# 🚗 Code de la Route Sénégal

Application interactive de quiz pour l'apprentissage des codes de la route au Sénégal

## 🎯 Objectif

Cette application est conçue pour vous aider à préparer l'examen du code de la route au Sénégal en testant vos connaissances de manière interactive et ludique.

## ✨ Fonctionnalités

- ✅ Quiz interactif avec 10 questions
- ✅ Explications détaillées pour chaque réponse
- ✅ Suivi de vos performances avec un score en pourcentage
- ✅ Interface moderne et responsive
- ✅ Adapté aux normes sénégalaises
- ✅ Design attrayant avec animations

## 🚀 Démarrage Rapide

### Accéder au site
Le site est déployé automatiquement sur GitHub Pages. Visitez:
https://max2dou.github.io/code-route-s-n-gal/

### Utilisation locale
1. Clonez le repository
```bash
git clone https://github.com/Max2dou/code-route-s-n-gal.git
cd code-route-s-n-gal
```

2. Ouvrez `index.html` dans votre navigateur

## 📊 Comment Fonctionne le Quiz

1. **Accueil**: Cliquez sur "Commencer le Quiz"
2. **Questions**: Répondez aux 10 questions une par une
3. **Résultats**: Consultez votre score et vos erreurs
4. **Explications**: Chaque réponse inclut une explication

## 🎓 À Savoir

- Les questions sont basées sur le code de la route sénégalais
- Chaque réponse correcte vaut un point
- Le score est affiché en pourcentage
- Les erreurs sont expliquées en détail
